# SiteGuard 演示命令清单

> 环境：Windows + Python 3.8+（`py` 换 `python3` 可用于 Linux/macOS）。
> 仓库根目录执行；核心链路零第三方依赖，可选功能依赖见括号内 optional 组。
> 固定标记词（每条命令末行）可作演示成功的判定依据。

| # | 命令 | 作用 | 预期输出（要点） |
| --- | --- | --- | --- |
| 1 | `py -X utf8 -m siteguard.cli datagen` | 生成样例语料与真值（幂等，seed=42 可复现） | JSON 清单列出 samples/gold/paired 文件 |
| 2 | `py -X utf8 -m siteguard.cli demo` | 两大场景端到端研判（规则通路，零依赖） | 两场景各"识别隐患 54 条"；报告落 `examples/demo_output/*.json|md` |
| 3 | `py -X utf8 -m siteguard.cli demo --docx` | 同上并导出 Word 报告（含签署栏） | 额外产出 `*.report.docx`（缺 python-docx 时打印提示跳过，exit 0） |
| 4 | `py -X utf8 -m siteguard.cli demo --with-vision` | 图文融合演示（视觉通路 optional `vision`） | 有图+依赖时报告含 `merged_from` 融合卡；缺依赖优雅降级 exit 0 |
| 5 | `py -X utf8 -m siteguard.cli build-kg` | 构建种子知识图谱 + 离线可视化（optional `kg`） | 187 节点/238 边，"已达标"；`examples/kg/kg.html` 单文件断网可开 |
| 6 | `py -X utf8 -m siteguard.cli eval` | 内置基准评测（零 API 依赖） | F1=1.0000、FP=0、端到端 108/108 误报 0，"达标" |
| 7 | `py -X utf8 -m siteguard.cli serve` | Web 面板（optional `web`：fastapi/uvicorn） | `http://127.0.0.1:8000`；页面零外链断网可演示；缺依赖打印安装提示 exit 2 |
| 8 | `py -X utf8 -B -m unittest discover -s tests` | 全量单元/集成测试 | `Ran 134 tests ... OK` |
| 9 | `py -X utf8 -m scripts.desensitize_audit` | 脱敏四步审查（可重跑） | 四步全 PASS，末行 `DESENSITIZE_AUDIT_OK` |
| 10 | `py -X utf8 -m scripts.verify_seed_data` | 种子数据完整性校验 | JSON/交叉引用/正则/迁移一致性全通过 |
| 11 | `py -X utf8 -m scripts.serve_http_smoke` | Web HTTP 层冒烟（TestClient，optional `web`） | 末行 `HTTP_SMOKE_OK 全部通过` |
| 12 | `py -X utf8 -m scripts.serve_live_demo` | Web 真实进程两场景演示（optional `web`） | 逐场景"上传→研判 54 条 → 下载三格式"，末行 `SERVE_LIVE_DEMO_OK` |
| 13 | `py -X utf8 -m siteguard.cli demo --vector-fallback` | 向量检索兜底（M6）：对无条款依据卡片补充候选条款 | 逐场景"向量检索兜底：N 张卡片补充候选条款（提示性，非判定依据）"；无空条款卡片时 N=0；纯 stdlib，评测零依赖 |
| 14 | `py -X utf8 -m siteguard.cli demo --video 现场视频.mp4` | 视频抽帧（M6）：关键帧参与图文融合（optional `video`，无需新模型） | "视频抽帧：N 帧关键帧"；缺 opencv/坏文件打印"视频抽帧降级"说明，exit 0 |

## Web 面板手动演示路径（对应验收门"CLI + Web ≥2 场景真实演示"）

```bash
py -m pip install fastapi uvicorn -i https://pypi.tuna.tsinghua.edu.cn/simple   # optional web 组
py -X utf8 -m siteguard.cli serve --port 8000
# 浏览器打开 http://127.0.0.1:8000：
#   1) 点"高处作业"/"临时用电"载入示例（或上传 .txt/.docx）→ 开始研判
#   2) 隐患卡片：风险等级徽章 / 原文摘录 / 依据条款（点击跳 kg.html 定位条文节点）/ 整改建议
#   3) 下载 JSON / Markdown / Word（含签署栏）三格式报告
```

命令行冒烟方式（不打开浏览器）：

```bash
curl -s http://127.0.0.1:8000/api/health
curl -s -F "file=@data/samples/text/demo_gczy.txt" http://127.0.0.1:8000/api/analyze
```

## 一键复现评测口径

```bash
py -X utf8 -m siteguard.cli datagen --force   # 样例与真值重新生成（seed=42 位级可复现）
py -X utf8 -m siteguard.cli eval              # 指标写入 examples/eval_report.json
```
