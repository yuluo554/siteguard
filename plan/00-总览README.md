# SiteGuard 项目计划总览

> 融合 LLM 与知识图谱的施工现场安全风险隐患智能研判系统

## 一句话定位

把施工日志 / 安全巡查记录 / 施工方案等非结构化文本（及现场图片，加分项），自动变成
**"隐患实体 → 关联规范条款 → 风险四级判定 → 可执行整改建议"** 的结构化研判结果，
全过程以**施工现场安全知识图谱**为推理骨干，LLM 仅做抽取兜底与行文生成，数值与分级结论
全部来自确定性规则，可评测、可复现、可解释。

## 核心设计决策（先读这里）

1. **规则优先，LLM 兜底**：隐患识别先走关键词+槽位+合法性校验的规则通路（零 API 依赖、
   可评测），LLM 只处理规则无法覆盖的口语化/长尾描述，且必须回传"原文摘录"做子串校验。
2. **统一中间表示 = "隐患条目卡"**：所有输入解析成同一结构（实体-类别-位置-置信度-证据），
   图文融合（加分项）就归约为条目卡的对齐合并。
3. **图谱即规则载体**：规范条文、阈值、风险分级标准都建成 KG 节点/属性，研判 =
   在图上做路径检索 + 规则判定，结论必须挂条款依据（防幻觉的根）。
4. **数据先行**：没有真实项目数据前，用程序化生成器自制带真值语料（可注入已知差异），
   评测零成本重复；规范条文以公开标准的条目做种子，标注"以官方文本为准"。
5. **Python 3.8 兼容**（本机环境），骨架零第三方依赖即可跑通 smoke test，
   重依赖（torch/dashscope 等）按里程碑分批引入。
