# 03 模块详设

## 1. 统一中间表示：隐患条目卡 HazardCard

所有输入（文本规则抽取、LLM 兜底、图像检测）统一产出此结构，后续研判/融合/入图只认它。

```json
{
  "card_id": "HC-000123",
  "source": {"file": "samples/inspection_log_001.txt", "type": "inspection_log", "offset": 42},
  "quote": "3#楼 12层 外架未满挂安全网",
  "extractor": "rules | llm | vision",
  "hazard_type": "临边防护缺失",          // 受控词表 kg/seed/hazard_types.json
  "category": "高处作业",                 // 受控大类：高处作业/临时用电/脚手架/基坑/机械/消防/其他
  "site_object": "外脚手架",              // 部位/设备，受控词表可扩展
  "work_type": "高处作业",
  "attrs": {"height_m": 33.0, "missing": "安全网"},
  "evidence": {"paragraph": 5, "line": 12},
  "confidence": 0.95,
  "merged_from": ["text", "vision"]       // 多模态融合后回填
}
```

字段纪律：`hazard_type/category/site_object` 必须落受控词表（LLM 输出映射不进去即丢弃或
标 `其他` + 待人工确认）；数值进 `attrs` 前过合法性范围表。

## 2. 研判结论结构 Judgment

```json
{
  "card_id": "HC-000123",
  "risk_level": "较大风险",               // 低风险|一般风险|较大风险|重大风险
  "rule_id": "RL-GCZY-004",
  "clause_refs": [{"standard": "JGJ 80-2016", "clause": "4.1.2", "quote": "临边作业时,应在临边设置防护栏杆"}],
  "suggestions": [
    {"text": "立即按 JGJ 80-2016 4.1.2 设置 1.2m 高防护栏杆并挂设安全网", "source": "measure:ME-GCZY-001"}
  ],
  "case_refs": ["CASE-2021-017"],
  "human_confirm": false                  // 多值/低置信度置 true，报告单列"待人工确认"
}
```

## 3. 模块清单与接口（骨架期签名冻结）

| 模块 | 职责 | 关键接口 |
| --- | --- | --- |
| `ingest/text_clean` | 伪空格/CRLF/全半角/BOM 清洗、行分段 | `clean_text(raw: str) -> str` |
| `ingest/parsers` | txt/docx 巡查日志→行记录 | `parse_log_file(path) -> list[HazardCard]` |
| `extract/rules` | 规则词典+槽位抽取（主通路） | `extract_cards(lines) -> list[HazardCard]` |
| `extract/llm` | LLM 兜底（可关） | `extract_cards_llm(lines) -> list[HazardCard]` |
| `extract/vision` | 图像检测（加分，M4） | `detect(image_path) -> list[HazardCard]` |
| `kg/schema` | 受控词表与节点/关系定义 | `load_schema() -> Schema` |
| `kg/builder` | 种子图谱装载 + 实例挂图 | `build(seed_dir) -> SimpleGraph` |
| `kg/visualize` | pyvis 离线 HTML（M3） | `export_html(graph, out)` |
| `reasoning/clause_linker` | 条目卡→条款关联 | `link(card, graph) -> list[clause_ref]` |
| `reasoning/risk_level` | 四级判定（规则引擎） | `judge(card, rules) -> Judgment` |
| `reasoning/suggest` | 建议生成（模板+LLM 行文） | `suggest(judgment, graph) -> list[suggestion]` |
| `pipeline/runner` | 端到端状态机+耗时记录 | `run(input_dir, out_dir) -> report` |
| `report/export` | 报告 JSON/MD（docx M5） | `export_md(report, out)` |
| `cli` | `run / demo / build-kg / eval / serve` | argparse 子命令 |

## 4. 规则库 schema（机器可读）

```json
{
  "rule_id": "RL-GCZY-004",
  "name": "临边作业未设置防护栏杆",
  "match": {"any_of": ["临边.*未(设置|安装).*栏杆", "防护栏杆缺失", "临边无防护"]},
  "category": "高处作业",
  "base_level": "较大风险",
  "override": [{"if": {"standard": "重大隐患判定标准2022", "hit": true}, "level": "重大风险"}],
  "clauses": [{"standard": "JGJ 80-2016", "clause": "4.1.2"}],
  "measure_ids": ["ME-GCZY-001"],
  "severity_hints": "描述性严重词(坠亡/坠落/伤亡)上调一档，封顶重大"
}
```

阈值表（`data/knowledge/thresholds/*.json`）与规则表同构：`param/op/value/unit/clause_ref`，
例如 `{"param": "防护栏杆高度", "op": "<", "value": 1.2, "unit": "m", "clause": "JGJ 80-2016 4.1.3"}`。

## 5. KG 种子图谱规模预算（保证 ≥100 节点）

| 节点类型 | 预算 | 来源 |
| --- | --- | --- |
| Regulation（条文块） | ~80 | JGJ59-2011 检查评分手册条目、JGJ80-2016、JGJ46(临电)、重大隐患判定标准2022 相关条 |
| HazardType | ~30 | 受控词表（高处作业8、临电7、脚手架5、基坑3、机械4、消防3） |
| Measure | ~25 | 条文措施 + 整改常用措施 |
| Case | ~10 | 公开事故通报脱敏摘要 |
| SiteObject/WorkType/RiskLevel | ~15 | 词表 |
| 合计 | **≈160** | 远超 100 节点要求，且全部离线可构建 |

## 6. 端到端状态机（pipeline/runner）

`加载输入 → 清洗 → 规则抽取 →(可选)LLM兜底 → 图融合(合并重复条目卡) → 条款关联
→ 分级判定 → 建议生成 → 报告导出 → KG 实例挂图`

每个节点记录耗时与成功/失败；单节点失败不中断（条目级降级），汇总到报告 `warnings`。
